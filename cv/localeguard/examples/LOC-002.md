# LOC-002 — ru-RU checkout total uses an unknown placeholder

**Classification:** Confirmed error  
**Severity:** Critical  
**Locale / key:** `ru-RU` / `checkout.total`  
**Screen:** Checkout → OrderSummary

## Steps to reproduce

1. Set the locale to `ru-RU`.
2. Open Checkout with a non-empty cart.
3. Render `checkout.total` with `amount=€1,249.00`.

## Expected

`Итого: €1,249.00`

## Actual

The translation requests `{sum}` although the application supplies `{amount}`. Rendering fails or exposes an unresolved placeholder.

## Evidence and recommendation

The baseline declares `{amount}` and `ru-RU` declares `{sum}`. Replace `{sum}` with `{amount}`; no application-code change is needed.
