Тестирование отказоустойчивости API

Smart API Chaos Tester

Безопасный local-first инструмент для запуска детерминированных сценариев отказа на разрешённом API и сбора фактических результатов его реакции.

  • Импортирует OpenAPI-описание или использует настроенный вручную запрос;
  • Моделирует ответы HTTP 500/429, тайм-ауты, задержки, повреждённые данные, обрывы соединения и ошибки авторизации;
  • Проверяет базовые ожидания и сохраняет историю запусков.

02 Рабочая демо-версия

Анализ логов и баг-репорты

AI Bug Investigator

Ориентированный на приватность QA-помощник: локально анализирует текстовые логи, находит ошибки, объединяет повторы и формирует структурированный баг-репорт.

  • Принимает текстовые логи в UTF-8 размером до 5 МБ и содержит готовый демонстрационный сценарий;
  • Группирует повторяющиеся ошибки, упрощая анализ результатов;
  • Может дополнительно улучшить отчёт локальной моделью Ollama, не отправляя лог в облачный сервис.
