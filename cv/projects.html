API resilience testing

Smart API Chaos Tester

A safe, local-first tool for running deterministic failure scenarios against an allowlisted API and collecting evidence about how it responds.

  • Imports an OpenAPI definition or accepts a configured request;
  • Simulates HTTP 500/429 responses, timeouts, delays, malformed payloads, connection drops, and authentication failures;
  • Checks baseline expectations and keeps a history of test runs.

Log analysis & bug reporting

AI Bug Investigator

A privacy-focused QA assistant that analyses text logs locally, finds errors, groups repeated issues, and prepares a structured bug report.

  • Accepts UTF-8 text logs up to 5 MB and includes a ready-to-run demo;
  • Consolidates repeated errors into clearer investigation results;
  • Can optionally enhance the report with a local Ollama model, without sending the log to a cloud service.

03 Live demo

Localization QA & bug reporting

LocaleGuard AI

A local-first tool that compares a baseline locale with translations, detects technical defects and language-specific risks, and prepares reproducible bug reports.

  • Accepts a baseline JSON and multiple translation files or runs a ready-made five-locale demo;
  • Checks keys, placeholders, ICU plurals, required tags, whitespace, terminology, UI length, and RTL/LTR risks;
  • Separates confirmed errors from heuristic warnings, generates structured reports, and exports the result as JSON.
